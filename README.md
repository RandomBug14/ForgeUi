# ForgeUI

ForgeUI est une application WPF en C# pour gérer et visualiser des données liées à Forge et à l’API Hypixel.

## Prérequis

- .NET 8 SDK
- Windows (application WPF)

## Démarrage

```bash
dotnet build
 dotnet run
```

## Dépôt GitHub

```bash
git remote add origin https://github.com/VOTRE_NOM_UTILISATEUR/ForgeUI.git
git push -u origin main
```
